# str-tax-housing
Tax implications of STR regulations

Currently this is a side repo to my project with Davide Proserpio and Marco Giacoletti on housing sales and tax implications of STR regulations.

City tax revenues data comes from the Urban Land Institute.

Regulation dates are provided by Airbnb and then hand-checked.

## Setup

Create `config.local.yaml` in this project's root directory. It should contain:

```
LOCAL_PATH: "<path to this project's root directory>"
DATA_PATH: "<path to the Dropbox folder containing the data>"
```
